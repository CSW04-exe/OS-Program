This project is a Java simulation of a process scheduler that manages and executes prioritized tasks using a custom synchronized priority queue. The program accepts input through standard input, where each line defines a process with its runtime, class, priority, and name, or issues a shutdown command. Real-time processes are always given priority over normal processes, and tasks are further sorted by numeric priority and arrival order. Five worker threads run concurrently, each retrieving the highest‑priority process, recording begin and end timestamps with millisecond accuracy, and simulating execution by sleeping for the specified duration. The queue implementation, thread synchronization, and MVC-inspired separation of responsibilities provide a clear demonstration of concurrent processing and custom data structure design in Java.
